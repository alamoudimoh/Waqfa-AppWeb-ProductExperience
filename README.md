# وقفة — الموقع العام

تجربة عربية من اليمين إلى اليسار تعرّف بوقفة، من الفجر إلى الليل، وتصل الزائر بالتطبيق على https://my.waqfa.app.

## التشغيل والتحقق

Node.js 24.18.1 وnpm 11.16.0. React 19.2.8 وTypeScript 5.9.3 وVite 8.2.1، مطابقة لتهيئة تطبيق وقفة المحلي وقت التنفيذ.

```bash
npm ci
npm run dev
npm run typecheck
npm run lint
npm run build
npm test
npm run preview
```

الخادم المحلي على المنفذ 4173. اختبارات Playwright تفحص نسخة الإنتاج؛ شغّل البناء قبلها. إذا لم يكن Chromium مثبتًا: `npx playwright install chromium`.

## الهوية

قُرئ ملفا `Waqfa-brand_identity.html` و`Waqfa-color_palette.html` كاملين قبل التعديل. هما مرجعان محفوظان دون تعديل؛ يثبت الاختبار بصماتهما الأصلية.

- `src/tokens.css`: الرموز الرسمية وأدوار العاج والزمرد وتوزيعها على أوقات اليوم.
- `src/components/Brand.tsx`: هندسة الشعار الأصلية، مع ألوان ترث ثلاثية السطح ومساحة آمنة تساوي عرض العلامة.
- `src/styles.css`: خط القاهرة للواجهة، وأميري للعلامة واللحظات التأملية؛ ارتفاع سطر عربي 1.9.
- `src/content.ts`: محتوى اللمحات ووجهة التطبيق.
- `src/components/`: التنقل ولمحات الورد والمتابعة والاستمرارية.
- `tests/experience.spec.ts`: فحوص الإنتاج والتجاوب ولوحة المفاتيح والإتاحة والهوية.

الخطوط محلية مع تراخيصها في `public/fonts`. لا صور مولّدة ولا مكتبات حركة أو أيقونات. التبعيتان التشغيليتان هما React وReactDOM فقط؛ أدوات الاختبار والتحليل تبعيات تطوير.

## النطاق

هذا الموقع تعريفي، ولا ينفّذ التطبيق المصادق عليه. الحالات المعروضة أمثلة توضيحية، وليست سجلات مستخدم أو أوقات صلاة أو نصوصًا شرعية. التفاعل محلي ولا يجمع بيانات أو يستخدم تتبعًا أو تخزينًا دائمًا.

يمكن ضبط وجهة التطبيق باستخدام `VITE_WAQFA_APP_URL`؛ تُقبل وجهة HTTPS فقط، وتعود القيمة غير الصالحة إلى النطاق المعتمد. لا يثبت اختبار الموقع توفر خدمة التطبيق الخارجية.

سطر «هذا التطبيق وقفٌ لله تعالى» دائم، مع نسبة العمل إلى محمد العمودي. لا تحذف الإهداء في أي سمة أو بناء.
