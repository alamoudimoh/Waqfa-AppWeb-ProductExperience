# وقفة — تجربة المنتج والواجهة التسويقية

صفحة وقفة التسويقية العامة: رفيق يومي هادئ للذكر والورد، من الفجر إلى الليل. الواجهة عربية بالكامل، بتخطيط من اليمين إلى اليسار، ومنفصلة عن التطبيق الداخلي.

## التشغيل

الإصداران المرجعيان للأدوات من مستودع التطبيق: Node.js 24.18.1 وnpm 11.16.0. يسمح نطاق المحرك بتحديثات سلسلة Node.js 24 وnpm 11 المتوافقة.

```bash
npm ci
npm run dev
npm run typecheck
npm run build
npm run preview
```

## التوافق مع التطبيق

نسخ مطابقة لملف الحزم في `alamoudimoh/Waqfa-App` وقت التنفيذ في ١٠ سبتمبر ٢٠٢٦:

| المكتبة | الإصدار |
| --- | --- |
| React وReact DOM | 19.2.8 |
| TypeScript | 5.9.3 |
| Vite | 8.2.1 |
| إضافة React إلى Vite | 6.0.5 |
| تعريفات React | 19.2.18 |
| تعريفات React DOM | 19.2.4 |
| تعريفات Node.js | 24.13.3 |

لا تحتاج صفحة تسويقية واحدة إلى موجّه أو طبقة جلب بيانات أو مخزن حالة عام؛ تستخدم حالة React المحلية للأوقات وقائمة الجوال. لم تُضف مكتبات تشغيل أخرى أو خدمة خلفية.

## الملفات

- `src/App.tsx`: الأقسام والنصوص والتفاعل والتنقل.
- `src/day-phases.ts`: الأوقات الستة والنصوص والألوان الخاصة بكل وقت.
- `src/styles.css`: النظام البصري، الخطوط المحلية، والتجاوب.
- `public/`: صورة الفجر والأيقونة والخطوط وتراخيصها.
- `docs/design-direction.md`: اتجاه التصميم، هيكل الأقسام، الألوان والخطوط والتجاوب.
- `docs/validation.md`: نطاق التحقق والحدود الفعلية.

## وجهة البدء

زر «ابدأ وقفتك» يفتح `https://my.waqfa.app`، وهو نطاق التطبيق الوارد في وثيقة المتطلبات. لتغيير الوجهة عند البناء، انسخ `.env.example` إلى `.env` واضبط `VITE_WAQFA_APP_URL`. لا تقبل الصفحة وجهة غير مشفّرة. إعداد القيمة لا يثبت جاهزية التطبيق أو توفره؛ التطبيق ونشره خارج نطاق هذا المستودع.

## الخصوصية والمحتوى

الصفحة لا تستخدم إعلانات أو تحليلات أو ملفات تعريف ارتباط أو تخزين متصفح، ولا تطلب بيانات شخصية. الخطوط والصورة تُقدّم من أصول المشروع نفسه. اللمحة المعروضة توضيحية وموسومة بذلك؛ لا تتضمن أوقات صلاة حقيقية أو مكتبة أذكار أو محتوى شرعي ثابتًا. النصوص التسويقية مستندة إلى وثيقة المتطلبات وطلب المالك، بما فيها أصل المشروع وحدود الخصوصية.

المشروع خاص؛ لا تمنح تراخيص الخطوط حق نشر شيفرة المنتج.
