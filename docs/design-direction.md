# الاتجاه المنفّذ

يوم يتغيّر ووقفة تبقى: تكوين تحريري يحمل معناه باللغة العربية والفراغ والسطوح الرسمية. الافتتاحية تربط اسم وقفة بالذكر والورد، ثم تتسع الصفحة لبيئة العاج قبل أن تهدأ في الزمرد.

## نظام واحد لست لحظات

| اللحظة | الرموز الرسمية | دورها |
| --- | --- | --- |
| الفجر | Midnight Navy ثم Emerald base وpanel | هدوء البداية والشعار الداكن |
| الصباح | Ivory base وsurface | الخطة اليومية والقراءة |
| الظهر | Ivory surface | المتابعة بين الأجهزة |
| العصر | Ivory surface-2 | الإكمال والمحاسبة الأسبوعية |
| المغرب | Emerald panel | المساحة الشخصية وأمانة المحتوى |
| الليل | Emerald base | الوقف والإهداء والدعوة الختامية |

كل قيمة لونية في رموز الإنتاج مأخوذة من الملفين الرسميين. لا تُستخدم لوحات Sovereign أو الألوان الدلالية لحالات الخدمة لتزيين مرور اليوم. الانتقالات بين بيئتي النهار والليل تقع في مناطق خالية من النص لتظل أزواج التباين مستقرة. الذهب للعلامة والفعل الأساسي فقط.

## الشعار والخط

الهندسة مأخوذة حرفيًا من رمز SVG في مرجع الألوان. يتحقق الاختبار من كل مسار. يتغير اللون عبر المتغيرات الموروثة فقط: ثلاثية السطح الفاتح في لمحة الورد، والداكن في الرأس والافتتاحية والختام والتذييل. المركز الذهبي ثابت. مساحة آمنة حول كل علامة تساوي عرضها، وأصغر علامة 24 بكسل. أيقونة المتصفح تستخدم المركز وحده وفق قاعدة الأحجام الصغيرة.

القاهرة للنصوص والعناوين العملية والتنقل. أميري للعلامة اللفظية وجملة الافتتاح التأملية والوقف والختام. ارتفاع السطر 1.9. لا ظلال أو توهج أو دوران للشعار.

## التفاعل

لمحة الورد تعرض أذكار الصباح والمساء والنوم عبر تبويبات رأسية. السهم الأيسر يتقدم والأيمن يعود، مع دعم الأعلى والأسفل والبداية والنهاية. لا يُعرض نص ديني غير مزوّد.

اختيار الهاتف أو الحاسوب يوضّح استمرار الحالة المؤكدة؛ لا يحاكي حساب مستخدم. الاستمرارية جدول أسبوعي موسوم كمثال، بعلامة ونص للحالة دون ترتيب تنافسي أو أرقام تكرار.

التنقل أصلي باتجاه العربية، والأزرار والحدود تستخدم الخصائص المنطقية. على الهاتف تتحول مساحة الشعار الافتتاحية إلى فاصل أفقي، ويظل تسلسل أوقات اليوم قائمًا عبر الصفحة. لا يوجد تمرير مفروض أو حركة مستمرة، ويوقف تفضيل تقليل الحركة الانتقالات والتمرير السلس.

## الوقف والنسبة

الإهداء جزء مقصود قبل الختام. يبقى النص الرسمي «هذا التطبيق وقفٌ لله تعالى» حرفيًا، ويُكرّر في التذييل مع نسبة العمل إلى محمد العمودي بالعربية.
