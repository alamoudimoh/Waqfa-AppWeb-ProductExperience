# وقفة — V3

## الهدف

تحافظ V3 على التكوين البصري المعتمد في V2، وتضيف أربع طبقات محددة دون تغيير هوية وقفة أو اختراع ألوان جديدة:

1. يبدأ الجو البصري للصفحة من مرحلة اليوم المحلية على جهاز الزائر: الفجر، الصباح، الظهر، العصر، المغرب، أو الليل. لا تُطلب صلاحية موقع ولا تُستخدم خدمة تحديد موقع.
2. يبقى شعار وقفة الرسمي حاضرًا أثناء التمرير، ويتحوّل تلقائيًا بين معالجة الهوية الفاتحة والداكنة بحسب المقطع الموجود خلفه.
3. يظهر مؤشر تقدم رفيع ومؤشر مراحل هادئ أثناء الرحلة، من دون صور أو عناصر زخرفية جديدة.
4. يصبح قسم الوقف واضحًا ومقصودًا، مع مشاركة مباشرة عبر مشاركة الجهاز وواتساب وتيليجرام وفيسبوك وإكس ونسخ الرابط.

## الخصوصية

لا توجد حزم مشاركة أو أدوات تتبع أو سكربتات خارجية. روابط المشاركة روابط ويب عادية، ومشاركة الجهاز تستخدم واجهة المتصفح عند توفرها.

## الاسم

لا يظهر اسم شخص في الواجهة أو التذييل. الرسالة الوحيدة المتعلقة بالملكية المعنوية في التجربة هي أن التطبيق وقفٌ لله تعالى.

## الهوية

جميع التحولات والألوان تستخدم الرموز الموجودة أصلًا في `src/tokens.css`. لا تضيف V3 أي قيمة لونية جديدة.

## التحقق المطلوب

```sh
npm run typecheck
npm run lint
npm run build
npm test
```

تشمل اختبارات V3 التحقق من بداية صباحية وبداية ليلية وفق ساعة الجهاز، ثبات الشعار أثناء التمرير، غياب اسم شخص من الواجهة، نطاقات المشاركة المسموح بها، واستمرار فحوص RTL والإتاحة والهوية الرسمية.
