# نطاق التحقق

- مطابقة إصدارات مكتبات الواجهة الأساسية مع مستودع التطبيق.
- فحص TypeScript وبناء إنتاجي بواسطة Vite.
- فحص وجود أصول الصورة والخطوط والأيقونة ومراجعها.
- فحص بنية المحتوى العربية واتجاه الصفحة والروابط الداخلية ووجهة البدء.
- مراجعة معالجة التبويبات وقائمة الجوال وحالات التركيز وتقليل الحركة في الشيفرة.

لم يُنفّذ اختبار متصفح أو فحص بصري آلي في هذه المهمة. لم تُختبر جاهزية التطبيق الداخلي أو الخدمة على نطاقه؛ الصفحة التسويقية لا تعيد تنفيذ التطبيق. يجب ألا تُفسّر مراجعة الشيفرة أو نجاح البناء على أنها نتائج لاختبار بصري أو تدقيق شامل لإتاحة الوصول.
